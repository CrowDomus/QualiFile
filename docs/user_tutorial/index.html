    QualiFile User Tutorial

    This guide is a complete, offline manual for every user-visible feature in QualiFile. It is designed for regulated documentation work: everything is local-only, operations are contained to your chosen root folder, and actions are clearly reported.

    Local-first: QualiFile runs a local server bound to 127.0.0.1. It does not access external networks for file operations. Your browser is only a UI for the local service.

    Core concepts

    • Root folder: the top directory QualiFile is allowed to manage.
    • Workspace: the file browser with folder tree, list/grid, and preview.
    • Projects: task & note tracking with optional timeline view.
    • Sync Manager: bulk Git Sync status and actions across rooted projects.
    • Tags and Notes: metadata stored alongside files/folders.

    Quick start

    1. Launch QualiFile (portable or embedded).
    2. Choose a root folder when prompted.
    3. Use the Workspace to create folders/files and attach notes/tags.
    4. Use Projects to track tasks, notes, and timelines.
    5. Use Sync Manager to run export/import and Git sync actions per project root.

    Getting started

    QualiFile manages documentation inside a single root folder. All file operations (create, rename, delete, copy/move) are constrained to that root. If you need to work with a different folder, update the root in Settings -> Workspace or from the first-run screen.

    Why a root folder? It keeps qualification evidence contained and reduces accidental edits outside scope.

    Installation & launch

    Portable (folder-based)

    • Run QualiFile.exe from the portable folder.
    • First launch asks for a root folder; the choice is stored under data/notes/root_state.json.
    • Exit safely via Settings -> Utilities -> Exit QualiFile to stop the local server.

    Portable (embedded / onefile)

    • Run the single executable; it extracts and launches the app.
    • Behavior is the same as portable: local-only server, root selection, same UI.

    Startup Progress Dialog (portable)

    • Shows startup stages and browser selection (if configured).
    • Uses safe, detected browsers only; no arbitrary executable paths.

    See also: Diagnostics & support for logs, and Troubleshooting for common startup issues.

    Workspace tour

    The Workspace is the main file-management screen with three panes: Folders (left), Files (middle), and Preview (right).

    Navigation & toolbar

    • Back/Forward/Up: traverse navigation history and parent folders.
    • Refresh: reload folder tree and file list.
    • Status pill: shows "Saved/Idle", "Loading...", "Moving...", etc.
    • Filter: quick search within the current folder.
    • Advanced filters: scope (current/root), folder name, tags, and date ranges.
    • Workspace root pill: click the current project pill to open a quick menu and switch to another linked project root.
    Advanced filter tips: use "Scope: All folders (root)" to search the entire root, filter by tags, and set modified date ranges (including custom start/end dates).
    • Scope: Current folder vs All folders (root).
    • Folder name: folder-only matching.
    • Tags: multi-select tags filter.
    • Date presets: last 24h, 7d, 30d, 90d, or custom range.
    • Apply / Reset: run or clear advanced filters.

    Toolbar actions

    • New Folder / New File: create items in the current folder.
    • Add note: add a note tied to the current folder or selection.
    • PDF Tools: merge PDFs, merge images into a PDF, or extract pages.
    • Capture: screenshot capture workflow (rectangle/window/screen).
    • Greenshot: launch external Greenshot with optional hotkey automation.
    • Import Structure: create folder trees from a template file.
    • Rename / Delete: operate on selected items.

    Layout & panes

    • Layout menu (top right): show/hide the Folders, Files, and Preview panes.
    • List/Grid toggle in the Files pane.
    • Actions menu in the Files pane: categorize files, show tag dots, and choose table columns.

    Folders pane

    • Tree view of folders under the current root.
    • Double-click to expand a folder.
    • Keyboard: Right expand, Left collapse, Enter select.
    • Drag & drop files/folders onto a tree node to move items.

    Files pane

    • List view with sortable columns (Name, Type, Size, Created, Modified).
    • Choose columns from the Actions menu in the Files pane.
    • Grid view for card-style browsing.
    • Grid thumbnails: common image files (JPG/JPEG/PNG/GIF/WEBP/BMP) show inline thumbnails when visible, including after folder navigation; other items keep icon placeholders.
    • Categorize groups items by tags; categories can be collapsed.
    • Tag dots show tag colors instead of full tag labels.
    • Selection: shift-click and ctrl/cmd-click for multi-select.
    • Inline rename: F2 on a selected item.

    Preview pane

    • Preview supported file types (PDF, PNG, JPG, TXT, source code).
    • Code syntax highlighting follows the selected app theme (Light, Light+, Dark, Dark+).
    • Buttons: Open file, Notes, Fullscreen, Show/Hide details, Clear.
    • Metadata panel includes type, size, modified/created, validation state, and full path.
    • Image controls: zoom, rotate, reset, annotate.
    • PDF controls: page count + Extract button.

    Unsupported file types show a download/notice card rather than preview content.

    Projects tour

    The Projects view manages projects, tasks, and notes, plus an optional timeline.

    Projects toolbar

    • Add note button for project-level notes.
    • Header alerts bell appears when task reminders become active; opening the dropdown marks current items as seen.
    • Use See all alerts to open the dedicated Alerts page with grouped alert states and per-item actions.
    • The Alerts page list expands to fill available page height by default for easier scanning.
    • Toggle between Tasks/Notes and Timeline views.
    • Layout menu controls side panel placement and content.

    Projects table

    • Create projects, link each to a root folder, and open them in Workspace.
    • Project create/edit includes a Tags section to import definitions from another rooted project (append missing tags or replace).
    • Columns can include status, description, root path, parent, created/modified.
    • Project color can appear as a name pill or a full row highlight.
    • Use Select Columns to show/hide optional columns.
    • Use the Layout menu to place the side panel (right/bottom/hidden) and choose its content (Tasks/Notes or Timeline).

    Sync Manager page

    • Open Sync from the left navigation to view all rooted projects in one table.
    • On desktop widths, the projects table and Activity panel fill the available page height and scroll internally.
    • If refreshes stop succeeding or become delayed, a Status may be stale badge appears; click it to refresh immediately. When live refresh is disabled, an Auto refresh OFF hint appears near the toolbar refresh button.
    • Each row shows Git state (branch/ahead/behind), metadata snapshot health, and local metadata state.
    • The table also includes a Local files summary using plain-language chips (for example: 1 modified, 2 untracked); internal Sync artifacts are excluded from these counts.
    • In Project pills mode, the project cell shows only the pill label (no secondary line underneath).
    • Use the inline Status legend and help panel for plain-language badge meanings and color cues.
    • Each row keeps a compact action set: Refresh plus ... (Sync settings).
    • Sync Manager now applies a deterministic recommendation so one next action is highlighted per actionable row (for example: Init Repo, Sync settings, Commit & Push, or Pull & Import), and the same recommendation is emphasized in the row context menu.
    • Open the per-project settings modal from ... to review compact tabbed sections: Overview, Remote, and Diagnostics.
    • Global Sync Manager preferences now live in Settings → Sync (auto refresh, interval, project color style, advanced inline row actions, and default Activity panel visibility).
    • Resize the Activity panel directly with the vertical drag handle; width is remembered automatically on this device (no width slider setting).
    • Right-click a project row (or press Shift+F10 on a focused row) to open context-menu shortcuts using the same menu style as Files/Projects: Sync settings, Refresh status, Commit & Push, Pull & Import, Export metadata, Import metadata, and Open folder; unavailable actions stay disabled.
    • Configure remotes from the modal Remote tab; Set Remote enables only when name/URL changes are detected, and credential-bearing URL previews stay redacted.
    • The row-level Set Remote action is removed to keep remote configuration centralized in settings.
    • The settings modal keeps only constrained recommended actions; use row/context-menu actions for the complete operation list.
    • The settings modal Diagnostics & smart hints section maps common safe error codes to next-step guidance and can copy sanitized command templates for support.
    • Use Settings → Sync → Project color style to switch between Project pills and Row colored display modes; this visual preference is local to your device.
    • Status columns keep concise badges only; helper text under Git/metadata indicators is removed to reduce row noise.
    • Use the Activity panel Filter by project box to isolate events by project name or project ID without deleting the timeline.
    • Diagnostics preview keeps project root paths redacted; Copy diagnostics template includes a full project-root command block for explicit support sharing.
    • Sync Manager auto-refreshes while visible and also refreshes when the window regains focus; the header shows the last refresh time.
    • The header also shows a live Refreshing/Running... status indicator while Sync Manager requests are in progress.
    • If repeated status refresh failures occur, polling temporarily backs off and automatically returns to the normal interval after a successful refresh.
    • Use the right-side Activity panel to review Started/Succeeded/Failed/Cancelled action events, copy the log, or clear it for the current tab session.
    • When destructive confirmations are required, Sync Manager prompts for large-delete confirmation first, then force-import phrase if required.
    • Per-action outcomes (success/failure) appear as bottom-right toasts; the in-page error banner is reserved for status-load failures.

    Tasks & Notes panel

    • Use the top toggle to switch between Tasks/Notes and Timeline modes.
    • Toggle between Tasks and Notes.
    • Filters: priority, status, date ranges, duration min/max, and project selection.
    • Option to show archived tasks.

    Project entry fields

    • Tasks: title, description, status, priority, color, start/end dates, parent task, reminder controls (on end date or X days before), and optional auto-rollup from children.
    • Disabling reminders on a task with an active alert now prompts you to either keep the active alert until completion or clear it immediately.
    • Notes: text, priority, status, color, deadlines, linked project, and optional parent task.
    • Each entry tracks created/modified metadata and supports copy-to-clipboard for descriptions.

    Timeline view

    • Timeline can follow the selected project or use a custom selection.
    • Controls: visible columns, zoom, hierarchy tree rows, link style, and highlight options.
    • Create tasks from timeline selection ranges.

    See also: Projects context menus and Projects settings.

    Notes & tags

    Notes

    • Notes are attached to a file or folder (local to that path).
    • Fields: text, deadline, priority (high/medium/low), status (none/in progress/closed), optional custom background.
    • Open notes and closed notes are shown separately; closed notes can be toggled.

    Tags

    • Assign tags to files and folders via context menu or capture/merge dialogs.
    • Tags can be color-coded and organized hierarchically.
    • Use tag dots or full tag labels in the Files pane.

    See also: Settings -> Tags & categories.

    Data & storage

    QualiFile stores operational data alongside your root or portable data folder.

    • data/preview_cache: rendered preview images and PDFs.
    • data/office_cache: Office-to-PDF preview cache.
    • data/notes: notes, root state, and small runtime files.
    • .qualifile_internal/qualifile.db: internal database (projects, validation, metadata).
    • .qualifile_meta.json and .qualifile_internal/: internal metadata folders.
    • Legacy sidecars may exist: .qualifile_tags.json, .qualifile_notes.json.
    • .qualifile_trash: soft delete location (if enabled).
    • data/logs and activity.log: operational logs.

    Portable mode keeps these within the portable folder unless QUALIFILE_DATA_DIR points elsewhere. Internal files are managed by QualiFile and should not be edited manually.

    Diagnostics & support

    • Check Settings -> About for version info.
    • Use logs in the data folder when reporting issues.
    • If support requests a bundle, follow their instructions to generate a support bundle and share only that bundle.

    Troubleshooting

    Port already in use

    QualiFile will choose a fallback port. The dialog will show the new URL.

    Browser doesn't open

    Use the "Open" button (or copy the URL). Ensure your default browser is set.

    Cannot set root folder

    Make sure the folder is accessible and is not a restricted path. Use the Browse button to avoid invalid paths.

    Capture fails

    If browser permissions block capture, try the legacy rectangle mode or use Greenshot.

    Preview unavailable

    Only PDF, PNG, JPG, TXT, and code files are previewed. Other file types show a notice.

    FAQ

    Is QualiFile offline?

    Yes. It uses a local server bound to 127.0.0.1.

    How do I back up?

    Copy the root folder and the data/ folder (portable mode). Avoid copying temporary caches if space is limited.

    Where are preferences stored?

    Preferences are stored in browser localStorage and in portable profile data (if profile mode is enabled).
